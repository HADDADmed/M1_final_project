New systematic review

Ask a research question. Get a PRISMA 2020 review.

Eight specialised agents write the protocol, search four scholarly databases, screen every record twice, read the full texts through a hybrid RAG index, extract verified evidence, appraise bias, synthesise, criticise and write the manuscript. You approve the critical decisions.

Architecture

Eight agents, one auditable graph

PRISMA-Agent is a LangGraph state machine. Every PRISMA stage is a node that reads and writes one typed, checkpointed state. A coordinator routes between stages, humans can intervene at two checkpoints, and every decision is written to an append-only audit trail.

Run it

Evaluation

Is it rigorous, and is it faster?

Measured on the end-to-end demonstration run: completeness (PRISMA 2020 checklist), accuracy (verified quotes, known-item recall), inter-agent consistency (Cohen's κ, reproducibility) and time saved compared with a manual review.
